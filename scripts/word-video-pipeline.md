# Word video lessons — pipeline rules

1. **Sentence ↔ video match (required)**  
   Write the toddler sentence to describe what appears on screen  
   (place + simple action). Never generic “I see X” or a random fact.

2. **Scene first, then sentence**  
   Pick scene → render 6s hop/land/wave with poster mascot →  
   write sentence that a kid would say about that frame.

3. **Unlock** only after full play (word ×3 + sentence).

4. **Offline** mp4 under `public/videos/{letter}-{slug}.mp4` + speech clips.
